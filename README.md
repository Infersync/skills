# Infersync skills

An open library of agent skills. Each skill is a folder with a `SKILL.md`, the
format Claude Code, Codex and Cursor already read: copy `<name>/SKILL.md` into
your repo's `.claude/skills/` and it works as it is.

Skills are ranked by receipts, not stars: how often runs that used a skill
passed an independent check, were sent back or stopped, and the minutes per
accepted step, against the same agents without it. Receipts are published
here as aggregate numbers only, with how many teams they come from.
